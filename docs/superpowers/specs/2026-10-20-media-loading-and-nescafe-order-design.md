# 媒体加载与雀巢页面顺序调整

## 目标

- 雀巢详情页按“最终主图 → 产品资产与场景”阅读，删除重复图片。
- 图片与视频在加载前保持稳定尺寸，加载完成后柔和淡入，避免页面跳动和破图感。
- 首要作品图优先加载，其余媒体按需加载；视频点击后再请求成片。

## 设计

1. 将雀巢最终主图和说明放入第一个内容区，位于产品资产图片之前。
2. 删除页面顶部独立封面和末尾重复的项目汇总。
3. 为图片容器提供米灰色占位；图片加载前透明，完成后以短淡入显示。
4. 在脚本初始化时处理已缓存图片，并监听其余图片的加载与失败状态。
5. 视频保持海报和固定比例，成片继续使用 `preload="none"`。

## 验证

- 检查雀巢页面内容顺序与重复项。
- 检查桌面和手机宽度下无布局跳动与横向溢出。
- 检查图片加载完成状态、失败状态和视频点击前状态。
- 发布后检查 GitHub Pages 对应提交。
